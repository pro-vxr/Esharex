GETTING STARTED

How to use eShareX

Connect nearby devices and share on the same local network.

1
Connect to the same network

Use the same Wi-Fi router, or turn on a hotspot on one phone and connect the other phone to it.

2
Open eShareX on the hosting phone

The first phone runs the local server. Keep eShareX open while others use the room.

3
Join from another device

Android users can select a nearby eShareX device when discovery is available. Browser users can enter the host address or scan its QR code.

No mobile data or internet is required for local communication. Your router or hotspot must allow devices to communicate with each other.
